# Frontend (Next.js 15)

Dashboard for [Lebanon CareerAI](https://github.com/SamiMaalouf/Career-AI). Full setup is in the [repo README](../README.md).

```bash
cp .env.example .env.local
# NEXT_PUBLIC_API_URL=http://localhost:8001
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). The API must already be running on port **8001**.
