3-minute video script — Lebanon CareerAI
Say the lines. Clicks in brackets. Upload a CV before you record so Coach and For you are already loaded.

0:00–0:20  PLAN  [Overview]
Lebanon’s youth unemployment is about 48 to 50 percent. Students hunt scattered boards, the same skill is written ten ways, and internships sit next to senior roles. I built Lebanon CareerAI: real public Lebanese ads, two matchers, and a coach for what to fix, learn, and apply to. Not a chatbot. Not the whole market.
[Show job count, internships, sources.]

0:20–0:40  HOW I BUILT IT  [steps 1–3]
I collect public postings, extract tools with an engineering taxonomy, and embed jobs and CVs. Then I rank keyword overlap versus a semantic Compatibility Score.
[Click Upload CV.]

0:40–1:10  COACH  [CV page]
Coach does three things: Fix the CV, Learn the tools these ads actually list, and Apply only where coverage is strong and seniority fits. Languages and soft skills do not count as Python or PLC.
[Scroll Fix / Learn / Apply.]

1:10–1:20  SKILL GAP
Skill Gap compares two paths using frequencies from this dataset.
[Show it. Keep moving.]

1:20–2:00  FOR YOU  [Jobs → For you, then Internships → For you]
For you shows keyword versus semantic. Each card says how many of that ad’s tools you match, and what is missing. Senior roles sit under Learn first. Internships have their own tab.
[Open one source link.]

2:00–2:40  RESULTS — how it is scored  [stay on a For you card]
Keyword score is mostly “what share of this ad’s tools are on your CV,” plus overlap of the two skill lists. Semantic score adds meaning: similar tools even if the words differ, then education, experience, and category—but only if there is a real technical match. English or teamwork cannot inflate a software role. Fifty percent coverage and a junior-fit title goes to Ready to apply; senior stretch roles go to Learn first. The number is an estimate, not a job offer.

2:40–3:00  CLOSE
Code is at github.com/SamiMaalouf/Career-AI. This will not hire anyone. It can tell a Lebanese engineering student what to fix, what to learn, and where to apply first.

If long: skip Skill Gap. Keep one For you card on screen during Results.
